# LollozzOs_Configurator
LOLLOZZ OS is a Windows 10/11 optimization suite built by Lollozz for competitive gaming and streaming. It locks system timers to 0.5ms, cuts input lag, strips telemetry/Copilot, and cleans bloatware. Includes automated tuning for OBS and Chrome, deep cache cleaning, and Visual C++/DirectX runtime deployment for peak FPS.
